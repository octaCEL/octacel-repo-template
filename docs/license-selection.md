# License selection

This template does not choose a project license. Before publishing or distributing code, the project owner should select a license that matches the intended use, dependencies, patent needs, and contribution policy.

- **MIT** is short and permissive, with limited conditions.
- **Apache-2.0** is permissive and includes express patent terms; preserve its notice and contribution requirements.
- **AGPL-3.0-or-later** requires network users of modified software to receive source under its terms.
- **Proprietary** use needs an owner-approved license and distribution policy.

Review dependency licenses and seek legal advice for questions about obligations or compatibility. Add the chosen license text and a `LICENSE` file in the same pull request that enables external distribution. Do not copy an unreviewed license file from another repository.
